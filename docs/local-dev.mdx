<h2 id="overview">Local Development</h2>

Use this guide after completing the [Installation Prerequisites](/docs/installation) and choosing a deployment target. This setup runs Codra locally using Wrangler for fast iteration.

<h2 id="setup">Setup</h2>

If you haven't already, clone your fork and install dependencies from the repository root:

```shell
npm install
```

Copy the example environment file:

```shell
cp .dev.vars.example .dev.vars
```

Fill in your secrets in `.dev.vars` (GitHub App credentials, database URL, etc.). For the `APP_PRIVATE_KEY`, ensure newlines are properly escaped as `\n`.

<h2 id="dev-server">Dev Server</h2>

Run database migrations, then start the development server:

```shell
npm run migrate
npm run dev
```

The development server runs two processes in parallel:
- `npm run dev:client` — Builds the Vite React dashboard in watch mode.
- `npm run dev:worker` — Starts the Cloudflare Worker locally via `wrangler dev`.

<h2 id="local-urls">Local URLs</h2>

Once the server is running, the dashboard and API are available locally:

- **Worker + Dashboard:** `http://127.0.0.1:8787`
- **OAuth Callback:** `http://127.0.0.1:8787/auth/github/callback`

<h2 id="providers">Next Steps</h2>

After the dashboard is running, navigate to **Settings > LLM Providers** to save provider API keys, refresh model catalogs, and choose the global model route.
