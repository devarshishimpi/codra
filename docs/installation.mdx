<h2 id="fork">1. Fork the Repository</h2>

Start by forking Codra into the GitHub account or organization that will own the deployment. Cloudflare's Git integration should point at your fork, not the upstream repository.

After forking, clone your fork locally and install dependencies:

```shell
git clone https://github.com/YOUR_ORG_OR_USER/codra.git
cd codra
npm install
```

<h2 id="github-app">2. GitHub App Setup</h2>

Codra uses a single GitHub App for both repository automation (webhooks, reviews, labels) and dashboard login (OAuth). Create a new GitHub App from **GitHub Developer Settings**.

### General App Settings

| Field | Value |
| --- | --- |
| Homepage URL | https://YOUR_WORKER_URL |
| Callback URL | https://YOUR_WORKER_URL/auth/github/callback |
| Webhook URL | https://YOUR_WORKER_URL/webhook |
| Webhook secret | A strong random string (save this for later) |

### OAuth Credentials

Once the App is created, note down your **Client ID** and generate a **Client Secret**.

### Subscribe to Events

Subscribe to **Pull request** and **Issue comment** events.

### Repository Permissions

| Permission | Access | Why |
| --- | --- | --- |
| Metadata | Read-only | Required by GitHub for repository access. |
| Contents | Read-only | Allows reading repository files when needed. |
| Pull requests | Read & write | Fetch PRs/diffs and create PR reviews. |
| Checks | Read & write | Create and update Codra check runs. |
| Issues | Read & write | Add and remove labels on pull requests. |

### Note Down App Details

For the installation setup later, make sure to keep track of:
1. The **GitHub App ID**.
2. A generated **Private Key** (downloaded as a `.pem` file).
3. The **Client ID** and **Client Secret**.
4. The **Webhook Secret**.

<h2 id="database">3. Database Setup</h2>

Codra uses PostgreSQL for persistence.

### Prepare your Database

Create a database in your preferred PostgreSQL provider (e.g., Neon, Railway, Supabase, Aiven, or a custom VPS). Ensure it is accessible via a standard connection string:

```text
postgresql://<user>:<password>@<host>:<port>/<db>?sslmode=require
```

Keep this connection string handy, as the setup script will use it to automatically configure a **Cloudflare Hyperdrive** connection pool for you.
